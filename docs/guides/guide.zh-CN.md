# 拾光绳使用教程

[项目首页](../../README.md) · [繁體中文](guide.zh-TW.md) · [English](guide.en.md) · [日本語](guide.ja.md)

## 安装与更新

在项目 Releases 中下载 0.4.1 对应平台的压缩包，先解压再运行。macOS 12+ 打开 `拾光绳.app`，可将它移到「应用程序」。Windows 10/11 x64 运行 `Clothesline.exe`，需要 Microsoft WebView2 Runtime。

这是未正式签名／公证的预览版。仅从你信任的项目发布页下载；若系统拦截，确认来源并按系统提供的正常打开流程操作，不要关闭整机安全保护。首次在 macOS 截图时，按系统提示检查「隐私与安全性 → 屏幕录制」权限，授权后可能需要退出重开。

更新时退出旧进程，替换应用文件，再打开新版。不要删除数据目录；记录不随程序文件替换而清空。

## 先认识几个入口

![挂绳总览](../media/overview.jpg)

顶部的「全部／截图／文字」筛选卡片；「日程」打开安排；时钟图标是历史记录。右边有粘贴、新建文字、截图、滚动截图、偏好设置与收起按钮。浏览器演示只展示交互；系统截图、托盘、原生拖出需要桌面程序。

## 收纳图片和文字

1. 在设置打开「自动收集截图」。使用系统、微信、钉钉等截图后，选择复制图片；来源软件名称不影响收纳。
2. 仅保存成文件的图片，可以拖入挂绳或点底部导入；也可在挂绳中按 `⌘/Ctrl+V`。
3. 普通文字不会自动收集。手动粘贴，或点「新建文字」输入内容；编辑时按 `⌘/Ctrl+Enter` 保存。
4. 卡片从左到右按时间排列；鼠标滚轮可浏览。单击查看大图或完整文字。
5. 卡片上的复制、保存、移除按钮分别把内容放入剪贴板、导出文件、移入历史。移除后可通过提示撤销。

单图最多 32 MB / 5000 万像素，单条文字最多 20000 字，挂绳最多 1000 项。超限会提示，不自动删除你的历史。

## 拖到其他应用

按住图片卡片或文字卡片，拖到接受图片文件／纯文本的输入区。目标应用不接受该拖放类型时，改用复制或导出。图片通过本地 PNG 文件传递；该功能需要桌面版，浏览器演示不支持原生拖出。Windows 和不同聊天应用的兼容性仍待真机反馈。

## 收起、位置和托盘

Esc 或收起按钮会变成 80×80 逻辑像素的小篮子。拖动篮子改变位置，单击再次展开。展开再收起、正常退出重启后保留位置；屏幕配置改变时会回到可见工作区。

Windows 的入口在右下角通知区域，可能被系统收到折叠区，不显示运行中的任务栏按钮。以前手动固定的旧快捷方式需自行右键取消固定。macOS 保留菜单栏入口，Dock 图标可在设置中开关。真正退出请用托盘菜单或设置中的「退出拾光绳」；macOS 也可用 Cmd+Q。

## 字号、主题和自动收起

![偏好设置](../media/settings.jpg)

偏好设置提供晴空浅蓝、静夜深色、暖纸米白、清晰高对比四套主题。界面字号 12–20px、正文字号 12–26px、时间说明 10–16px，卡片宽度 140–260px；更改会保存。

「无操作后自动收起」可选常用时长或自定义 1–86400 秒，0 为永不隐藏。编辑、截图和拖出期间暂停计时。可调整展开高度，或拖挂绳边缘改变尺寸。

## 历史记录

![历史记录](../media/history.jpg)

打开顶部时钟入口，可搜索、按图片／文字和记录状态筛选，预览、复制或重新挂上。卡片移入历史后，重启也保留。永久删除需要再次确认；永久删除会移除对应记录及图片文件，无法通过应用恢复。

觉得旧版记录少了，先在设置查看数据目录，再用「导入旧记录」选择包含旧 `shelf.json` 的目录进行合并。不会改动旧目录。请先备份，不要上传私人索引供他人查看。

## 日程

![日程示例](../media/schedule.jpg)

点「文字」旁的「日程」，切换当天、本周或本月，使用新建按钮填写标题、日期、时间；可选全天或跨天日期区间。保存后可编辑、标记完成。这里是本地安排列表，目前没有系统通知、提醒闹钟或云日历同步。

## 滚动截图

1. 打开要截的页面，点「滚动截图」，拖出内容区域，松开鼠标确认。
2. 小控制台出现后，将鼠标移回目标应用，手动向下滚动，保留相邻画面的重叠。
3. 自动采集会尝试匹配并拼接。提示对不上时往回滚一点；固定导航／重复图案可改用重叠比例和「手动补采」。
4. 点「完成并挂上」生成 PNG 长图；取消会放弃本次采集。

程序不会自动替你滚动页面。默认主屏幕，过程中不要移动目标窗口、改变选区或分辨率。最多 2400 万像素、32760px 高，并受 32 MB 单图限制；复杂页面和 Windows 原生采集兼容性仍待更多实测。

## 快捷键

| 操作 | macOS | Windows |
| --- | --- | --- |
| 区域截图（全局） | Ctrl+Option+A | Ctrl+Alt+A |
| 滚动截图（全局） | Ctrl+Option+S | Ctrl+Alt+S |
| 粘贴到挂绳（应用获得焦点） | Cmd+V | Ctrl+V |
| 新建文字（应用获得焦点） | Cmd+N | Ctrl+N |
| 保存便签（编辑时） | Cmd+Enter | Ctrl+Enter |
| 收起／返回 | Esc | Esc |

全局快捷键可在设置关闭；注册冲突会提示。编辑框内的 Esc 优先关闭当前面板。

## 数据与常见问题

数据目录：macOS 为 `~/Library/Application Support/Clothesline`，Windows 为 `%AppData%\Clothesline`。备份整个目录可保留索引与原图；程序每次保存也保留上次有效索引备份。关闭程序后再备份更稳妥。

- **没收到截图**：确认来源真的复制了图片，自动收集开关开启；仅保存的文件需导入。敏感剪贴板标记会被跳过。
- **Windows 打不开**：确认 x64 系统与 WebView2 Runtime，查看系统阻止提示。提供版本和复现步骤到 Issue，不要上传私密数据。
- **macOS 截图无效**：检查屏幕录制权限，按系统提示退出重开；不要关闭全局安全保护。
- **拖放没反应**：目标程序可能只接受文本或文件，先用复制／保存；反馈目标应用版本与系统缩放。
- **多语言在哪里切换**：目前只有教程翻译为四语，应用界面仍为中文。

更多验证边界见 [VALIDATION.md](../VALIDATION.md)。所有配图均为新建示例数据的浏览器演示截图。

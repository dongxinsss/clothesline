# Clothesline の使い方

[ホーム](../i18n/README.ja.md) · [简体中文](guide.zh-CN.md) · [繁體中文](guide.zh-TW.md) · [English](guide.en.md)

## インストールと更新

Releases から 0.4.1 の対応ファイルをダウンロードし、展開してから起動します。macOS 12 以降では `拾光绳.app` を開きます。「アプリケーション」への移動も可能です。Windows 10/11 x64 では `Clothesline.exe` を実行し、WebView2 Runtime を用意してください。

プレビュー版は正式なコード署名／Apple の公証を受けていません。信頼できる配布元から入手し、OS の通常の許可手順に従ってください。システム全体の安全機能は無効にしないでください。macOS の初回撮影時は「プライバシーとセキュリティ → 画面収録」の案内に従い、必要なら終了して再起動します。

更新時は旧版を終了し、アプリのファイルを入れ替えます。データのフォルダーを残せば履歴と設定を引き継げます。

## 画像とメモを掛ける

![カード一覧のデモ](../media/overview.jpg)

1. 設定の「自动收集截图」を有効にし、スクリーンショットを画像としてクリップボードにコピーします。撮影元のアプリは問いません。
2. ファイルとしてのみ保存した画像は、棚へドラッグするか読み込みます。棚にフォーカスがあるときは Cmd/Ctrl+V でも貼り付けられます。
3. 通常のコピー文章は自動記録しません。手動で貼り付けるか「新建文字」で作成し、編集中の Cmd/Ctrl+Enter で保存します。
4. カードは時間順に左から並びます。ホイールで移動し、クリックで拡大。カードの操作からコピー、保存、履歴への移動ができます。移動直後には取り消しの案内が出ます。

画像は 32 MB／5000 万画素、メモは 20000 文字、棚のカードは 1000 件までです。超過時はエラーを表示し、履歴を自動削除しません。

## 他のアプリへドラッグ

カードを押したまま、画像ファイルやプレーンテキストを受け付けるアプリにドラッグします。画像はローカルの PNG ファイルとして渡します。拒否される場合はコピーやファイル保存を使用してください。ブラウザのデモではネイティブの外向きドラッグは使えません。Windows や各チャットアプリとの互換性は実機での確認が必要です。

## 折りたたみと常駐アイコン

Esc または折りたたみボタンで 80×80 論理ピクセルのバスケットになります。ドラッグで移動し、クリックで開きます。開閉や正常な再起動後も位置を保持し、画面構成が変わると見える作業領域内に戻します。

Windows は右下の通知領域に常駐し、実行中のタスクバーボタンは表示しません。アイコンが隠れている場合は通知領域の展開部分を確認してください。手動でピン留めした古いショートカットは別途解除します。macOS にはメニューバーの入口があり、Dock 表示は設定できます。終了は「退出拾光绳」、macOS では Cmd+Q も使用できます。

## 見た目と自動折りたたみ

![設定のデモ](../media/settings.jpg)

青、ダーク、紙、高コントラストの 4 テーマがあります。UI 文字は 12–20px、本文は 12–26px、説明は 10–16px、カード幅は 140–260px に変更でき、設定は保存されます。

「无操作后自动收起」で無操作時の時間を選択、または 1–86400 秒を指定します。0 は自動で隠さない設定です。編集中、撮影中、ドラッグ中は停止します。高さの設定や棚の端のドラッグでサイズも変えられます。

## 履歴と予定

![履歴のデモ](../media/history.jpg)

時計アイコンの「历史记录」では検索、画像／文章や状態による絞り込み、プレビュー、コピー、再配置ができます。履歴は再起動後も残ります。完全削除には再確認が必要で、記録と画像ファイルが消え、アプリからは元に戻せません。

以前の記録が見つからないときは設定のデータの場所を確認します。「导入旧记录」で旧 `shelf.json` を含むフォルダーから統合できます。元のフォルダーは変更しません。先にバックアップし、個人の履歴を公開しないでください。

![予定のデモ](../media/schedule.jpg)

「文字」の隣の「日程」で日・週・月表示を切り替えます。タイトル、日付、任意の時間、終日や期間を指定し、編集や完了の操作ができます。通知、アラーム、クラウドカレンダー同期は現在ありません。

## スクロール撮影

1. 対象のページを開き、「滚动截图」で撮る領域をドラッグして選択。マウスを離すと確定します。
2. 小さな操作パネルが出たら対象アプリへマウスを戻し、前の画面と重なる部分を残しながら自分で下へスクロールします。
3. 自動取得が画像をつなぎます。合わない場合は少し戻すか、手動の重なり率と「手动补采」を使います。
4. 「完成并挂上」で長い PNG を保存します。キャンセルすると今回の取得は破棄します。

自動スクロールはしません。対象は主画面で、途中でウィンドウ、領域、解像度を変えないでください。最大 2400 万画素、32760px 高、32 MB です。固定ナビゲーションや繰り返し模様は失敗の原因となり、Windows の実機確認も必要です。

## キー操作と困ったとき

全体の撮影キーは macOS Ctrl+Option+A／Windows Ctrl+Alt+A、スクロール撮影は A の代わりに S です。アプリにフォーカスがあるとき、Cmd/Ctrl+V で貼り付け、Cmd/Ctrl+N でメモ、編集中の Cmd/Ctrl+Enter で保存。Esc は開いたパネルを先に閉じます。全体のキー登録は設定から無効にできます。

保存先は macOS `~/Library/Application Support/Clothesline`、Windows `%AppData%\Clothesline` です。終了後にフォルダー全体をバックアップすると、索引と画像を保持できます。

- 画像が入らない：画像としてコピーしたか、自動収集が有効か確認。機密指定のクリップボードは除外されます。
- Windows が起動しない：x64 と WebView2 Runtime、OS の確認画面を調べ、私的なファイルを添付せず再現手順を報告します。
- macOS の撮影失敗：画面収録の許可を確認し、案内に従って再起動します。
- ドラッグの失敗：コピー／保存を使い、相手アプリの版と画面の拡大率を添えて報告してください。
- 表示言語：4 言語に対応するのはドキュメントです。UI は現在中国語です。

0.4.1 はプレビュー版で、Windows はクロスコンパイルのみです。[検証記録](../VALIDATION.md)も確認してください。図は新しく作ったサンプルデータによるブラウザの操作デモです。

# 拾光繩使用教學

[首頁](../i18n/README.zh-TW.md) · [简体中文](guide.zh-CN.md) · [English](guide.en.md) · [日本語](guide.ja.md)

## 安裝與更新

從 Releases 下載 0.4.1 的對應系統壓縮檔，解壓縮後執行。macOS 12+ 開啟 `拾光绳.app`，也可移入「應用程式」；Windows 10/11 x64 執行 `Clothesline.exe`，需要 WebView2 Runtime。

預覽版尚未正式簽署／Apple 公證。請從可信任的發布頁下載，依系統正常流程開啟，不要關閉整機安全防護。macOS 首次截圖請依提示檢查「隱私權與安全性 → 螢幕錄製」權限，需要時退出再開。

更新時先退出舊版，替換程式檔再重開。保留資料目錄即可沿用記錄與設定。

## 收納截圖與文字

![掛繩示例](../media/overview.jpg)

1. 在偏好設定開啟「自动收集截图」。微信、釘釘或系統截圖工具只要將圖片複製到剪貼簿，就能收納。
2. 只儲存成檔案的截圖請拖入掛繩，或點底部匯入。掛繩取得焦點時可按 `⌘/Ctrl+V`。
3. 一般複製的文字不會自動記錄；可手動貼上或使用「新建文字」，編輯中按 `⌘/Ctrl+Enter` 儲存。
4. 卡片依時間由左至右排列，可用滑鼠滾輪瀏覽、點擊放大。卡片上的按鈕可複製、匯出或移入歷史，移除後會顯示復原入口。

每張圖片最多 32 MB／5000 萬像素，每則文字最多 20000 字，掛繩最多 1000 項，超過會提示，不會自動刪除歷史。

## 拖到其他應用程式

按住卡片拖到接受圖片檔案或純文字的位置。圖片以本機 PNG 檔案傳遞；相容性取決於目標程式，不接受時可改用複製／匯出。這需要桌面版，瀏覽器展示不支援原生拖出。Windows 與各聊天工具尚需真機驗證。

## 小籃子與常駐入口

Esc 或收起按鈕會變成 80×80 邏輯像素的小籃子。拖動改變位置，點擊展開；展開再收起與正常重啟會保留位置，螢幕變更後限制在可見工作區內。

Windows 只保留右下角通知區托盤入口，可能在隱藏圖示區；不顯示執行中的工作列按鈕。以前手動釘選的捷徑請自行取消釘選。macOS 可用選單列，Dock 圖示可在設定切換。真正退出請用「退出拾光绳」，macOS 也可按 Cmd+Q。

## 主題、字級與自動收起

![設定畫面](../media/settings.jpg)

四種主題為淺藍、深色、暖紙與高對比。介面 12–20px、正文 12–26px、時間說明 10–16px、卡片寬度 140–260px，可獨立調整並保存。

「无操作后自动收起」可設定常用時間或自訂 1–86400 秒，0 代表永不隱藏；編輯、截圖、拖出期間暫停。可調整展開高度或拖動掛繩邊緣改變大小。

## 歷史與日程

![歷史記錄](../media/history.jpg)

時鐘按鈕開啟「历史记录」，可搜尋、依圖片／文字及狀態篩選、預覽、複製、重新掛上。移入歷史後重啟仍保留。永久刪除需再次確認，會移除記錄與圖片，應用程式無法復原。

舊版資料不見時，先確認設定內的資料目錄；「导入旧记录」可合併含舊 `shelf.json` 的資料夾，不改動來源。請先備份，不要公開私人索引。

![日程示例](../media/schedule.jpg)

「文字」旁的「日程」提供今天／本週／本月視圖。新建時填標題、日期與選填時間，也可設全天或跨天，之後可編輯及標記完成。目前無系統通知、鬧鐘或雲端日曆同步。

## 滾動截圖

1. 開啟目標頁面，點「滚动截图」，拖曳選取內容區，放開滑鼠確認。
2. 出現小控制台後，將滑鼠移回目標程式，手動向下捲動並保留重疊畫面。
3. 自動取樣會嘗試拼接；提示無法對齊時向回捲一點，固定導覽／重複圖案可用手動重疊比例和「手动补采」。
4. 點「完成并挂上」產生長 PNG，或取消本次取樣。

程式不會代替你捲動頁面。預設主螢幕，過程中不要移動目標視窗、選區或變更解析度。限制為 2400 萬像素、32760px 高及 32 MB；複雜頁面與 Windows 原生功能仍需更多實測。

## 快捷鍵與疑難排解

全域截圖：macOS Ctrl+Option+A／Windows Ctrl+Alt+A。全域滾動截圖改用 S。應用程式取得焦點時 Cmd/Ctrl+V 貼上、Cmd/Ctrl+N 新建文字、編輯中 Cmd/Ctrl+Enter 儲存。Esc 優先關閉面板，再收起掛繩；全域快捷鍵可在設定停用。

資料位於 macOS `~/Library/Application Support/Clothesline`，Windows `%AppData%\Clothesline`。退出後備份整個資料夾，包括索引與圖片。

- 沒收進截圖：確認已複製圖片並開啟自動收集，只有檔案時請匯入；敏感標記內容會跳過。
- Windows 開不了：檢查 x64 與 WebView2 Runtime，保留系統安全設定，提供版本與重現步驟。
- macOS 截圖失敗：確認螢幕錄製權限，依提示重開程式。
- 拖放失敗：先使用複製／匯出，回報目標程式版本與縮放比例。
- 語言切換：四語支援指文件，程式介面目前仍為中文。

0.4.1 為預覽版，Windows 僅交叉編譯，尚未真機驗證；詳見[驗證記錄](../VALIDATION.md)。配圖皆為僅含示例資料的瀏覽器操作展示。

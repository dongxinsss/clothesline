# Clothesline · 拾光绳

**Hang onto a screenshot. Get back to your work.**

A local desktop shelf for screenshots, notes, and schedules on macOS and Windows. Open it as a clothesline of cards; fold it into a small, draggable basket.

[Download preview](https://github.com/dongxinsss/clothesline/releases) · [User guide](../guides/guide.en.md) · [Report a problem](https://github.com/dongxinsss/clothesline/issues)

![Clothesline interactive demo with sample content](../media/overview.jpg)

## A place for things you will need in a minute

- Catch new clipboard images automatically. Ordinary copied text is not collected automatically.
- Paste text or images, import image files, and write a note without leaving the shelf.
- Drag cards to apps that accept them, or copy and export. Target-app compatibility needs testing.
- Keep history across restarts and bring archived cards back to the line.
- Plan in day, week, and month views. Choose four themes, independent font sizes, and an idle-collapse timeout.
- Use roughly 20% of the available screen height by default, or collapse to an 80×80 logical-pixel basket.

## Try it in a minute

1. Download and extract the package for your OS from Releases. Open `拾光绳.app` on macOS or run `Clothesline.exe` on Windows.
2. Check **自动收集截图** (automatic screenshot collection) in settings, then copy a non-sensitive screenshot.
3. Use **新建文字** (new note) to jot something down. Press Esc to fold the shelf; click the basket to reopen it.
4. Explore **历史记录** (history) and **日程** (schedule), including day/week/month views.

## Platform status

macOS 12+ has a universal Apple Silicon / Intel build. Windows 10/11 x64 requires WebView2 Runtime. Version 0.4.1 is a preview: macOS has local hardware checks; Windows is cross-compiled and has not been tested on a Windows host. Schedules do not include notifications or cloud calendar sync.

**Documentation is multilingual; the application interface is currently Chinese.** Screenshots show the browser demo with synthetic data, not proof of native Windows integration.

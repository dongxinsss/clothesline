# 拾光绳 · Clothesline

**スクリーンショットを掛けて、作業の続きへ。**

macOS と Windows 向けの、画像・メモ・予定を手元に置けるデスクトップツールです。開くとカードを掛けるロープに、折りたたむとドラッグできる小さなバスケットになります。

[プレビュー版をダウンロード](https://github.com/dongxinsss/clothesline/releases) · [使い方](../guides/guide.ja.md) · [不具合を報告](https://github.com/dongxinsss/clothesline/issues)

![サンプルデータを使用した操作デモ](../media/overview.jpg)

## あとで使うものを、すぐ手の届く場所に

- クリップボードにコピーした画像を自動収集。通常のテキストは自動記録しません。
- 画像や文章の貼り付け、画像ファイルの読み込み、メモの作成に対応。
- 対応するアプリへカードをドラッグ。コピーやファイルへの保存も可能です。相手側アプリとの互換性は確認が必要です。
- 再起動後も履歴を保持し、取り外したカードを再び掛けられます。
- 日・週・月の予定表示、4 種類のテーマ、個別の文字サイズ、無操作時の折りたたみ時間を設定できます。
- 初期状態では使用可能な画面の高さの約 20%。折りたたむと 80×80 論理ピクセルになります。

## まず試してみる

1. Releases から OS に合うファイルをダウンロードして展開します。macOS では `拾光绳.app`、Windows では `Clothesline.exe` を開きます。
2. 設定の「自动收集截图」を確認し、個人情報を含まない画像をコピーします。
3. 「新建文字」でメモを作成。Esc で折りたたみ、バスケットをクリックして開きます。
4. 「历史记录」で履歴、「日程」で今日・今週・今月の予定を確認できます。

## 対応状況

macOS 12 以降向けに Apple Silicon / Intel ユニバーサル版を提供します。Windows 10/11 x64 では WebView2 Runtime が必要です。0.4.1 はプレビュー版です。macOS はローカル実機で確認済みの項目がありますが、Windows はクロスコンパイルのみで実機未検証です。予定の通知やクラウド同期はありません。

**多言語に対応しているのは説明書です。アプリの画面は現在中国語です。** 画像はサンプルデータを使ったブラウザ版デモであり、Windows のネイティブ機能の動作確認を示すものではありません。
